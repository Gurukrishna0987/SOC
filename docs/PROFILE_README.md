## After you paste it

1. **Add a profile picture and a banner.** A dark, simple banner with your
   name and "SOC Analyst" reads better than a meme. Canva has free
   developer banners.
2. **Pin the SOC repo** to the top of your profile (Profile picture dropdown →
   "Pin repository").
3. **Add the repo to your "Featured"** section as well.
4. Update the email and LinkedIn handle before publishing.
5. Keep it short. Recruiters read the first two lines and the pinned repo.

## Optional widgets

GitHub profile READMEs support images. Two that work well and cost nothing:

```markdown

![](https://github-readme-stats.vercel.app/api/top-langs/?username=Gurukrishna0987&layout=compact&theme=tokyonight)
```

They render the language breakdown of your public repos, which for this
project is mostly Python — which is fine and honest. A "streak" widget is
gimmicky; skip it.

## One thing to avoid

Do not put a wall of certification badges you have not earned, and do not put
a "Goals 2026" list. Recruiters ignore both. The pinned repository is the
only thing on this page they will actually click.
